# UniSync-frontend
Smart Finance Managing Application for University Students

## 📱 Frontend Setup (Expo React Native)

```bash
cd UniSync-frontend
npm install   # If dependencies are needed
npm start     # Starts the Expo developer tools
```

You can also run platform-specific commands from the `frontend` directory:
- `npm run android` - Start on Android emulator/device
- `npm run ios` - Start on iOS simulator
- `npm run web` - Start on web browser
